# Shivsagar Flood Relief - Impact & Donation Report

An interactive, minimal, and premium browser-based dashboard website designed to present donation insights, analyze contribution statistics, search donors, and generate custom certificates of appreciation.

## 🚀 Key Features

1. **Simple CSV Dropzone**:
   - Simply upload your `shivsagar_flood_relief_donations.csv` exported from the Tracker app to instantly populate the dashboard.
2. **Interactive Chart Visualizations**:
   - **Donations by Village**: Interactive doughnut chart showcasing contributions from different villages using Chart.js.
   - **Contribution Slab Analysis**: Bar chart classifying donors by their contribution size (e.g. ₹1-₹200, ₹201-₹500, ₹501-₹1000, ₹1000+).
3. **Public Searchable Donor Directory**:
   - Perform real-time filter-as-you-type searches on first names, last names, and villages.
4. **Appreciation Certificate Generator**:
   - Click "View Cert" next to any donor to instantly draw a beautiful certificate on an HTML5 canvas.
   - You can download the generated certificate directly as a high-quality `.png` image for sharing or printing.

## 🛠️ How to Use

1. Double-click [index.html](file:///home/angsuman/shivsagar-flood-relief-report/index.html) in your browser.
2. Drag and drop the CSV file generated by the Tracker tool, or click to select the file.
3. Explore the graphs, search for specific entries, and generate beautiful appreciation certificates for donors.
