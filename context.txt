# ANGSUMAN Repository Context

This repository (`https://github.com/Angsumi/ANGSUMAN`, live at `https://Angsumi.github.io/ANGSUMAN/`) serves as the central hub for Angsuman Das's personal portfolio, academic credentials, research publications, and professional documentation.

# Directory Structure

*   **`documents/academic/`**: Academic transcripts, degree certificates, and marksheets (10th, 12th, B.Sc., M.Sc.).
*   **`documents/certificates/`**: PGDCA diploma, Genomic Data Science specialization, and additional certifications.
*   **`documents/competitive_exams/`**: Scorecards and certificates for CSIR-UGC NET JRF, IELTS Academic, and SLET.
*   **`documents/identity_and_personal/`**: Passports, ID cards, PRC, and demographic documents.
*   **`documents/recommendations/`**: Letters of Recommendation from academic guides, professors, and supervisors.
*   **`documents/publications/`**: Research papers, review articles, and scientific publications.
*   **`documents/resume/`**: Compiled CV and resume documents.
*   **`documents/study_materials/`**: Scikit-Learn cheat sheet, Pandas notes, data science program guides, and study materials.
*   **`documents/work_and_experience/`**: Offer letters, appointment letters, teaching experience certificates, and workshop certificates.
*   **`images/`**: Web asset images used in the portfolio interface.
*   **`index.html`**: Primary interactive portfolio landing page.
*   **`download.html`**: Interactive document viewer and credential download portal.
*   **`style.css` / `script.js`**: Core styling and interactive logic for the web portal.

# Instructions for AI & Collaborators
* All relative document links in `index.html` and `download.html` link directly to raw assets in this repository (`https://raw.githubusercontent.com/Angsumi/ANGSUMAN/main/...`).
* Maintain clean snake_case filenames when adding new documents.
